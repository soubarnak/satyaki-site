# Satyaki Space Coder

Satyaki Space Coder teaches Python 3 and Java to learners aged 10 to 13 through a 3D space coding quest. Twenty-five Missions in five Planets, each Planet closed by a Boss Gate, lead to the Playground and the Arena.

## Language

### Journey

**Mission**:
One ordered exercise teaching exactly one new coding concept.
_Avoid_: Level, lesson, stage, module

**Planet**:
A themed group of five Missions.
_Avoid_: World, unit, chapter

**Boss Gate**:
The gate after a Planet's five Missions, required to unlock the next Planet.
_Avoid_: Boss level, exam, final test

**Pass**:
State where a Mission's required final or intermediate World State holds. Pass awards Star 1.
_Avoid_: Win, complete, solved

**Star**:
Mission award in three grades: Star 1 for a Pass, Star 2 for a Pass within par, Star 3 for a Pass that uses the Planet concept.
_Avoid_: Badge, trophy, medal, points

**Par**:
The max steps and max energy within which a Pass also earns Star 2.
_Avoid_: Limit, target time, score

### People and progress

**Cadet**:
The learner, aged 10 to 13.
_Avoid_: Player, student, user (in learner-facing text)

**Account**:
The verified login record holding one Cadet's synced progress. Used in auth and developer text only, never learner-facing text.
_Avoid_: User, profile (for this record)

**Save Code**:
An export/import string carrying progress for logged-out use and device moves. It is not program code, not a password, and not proof of identity.
_Avoid_: Save file, backup code, recovery code

**Skill Radar**:
A five-axis picture of a Cadet's progress, one axis per Planet, scored from Mission Stars.
_Avoid_: Skill chart, stats, ability score

**Daily Recall Drill**:
The one optional Mission replay offered each day to revisit an earlier Pass.
_Avoid_: Daily challenge, revision quest, homework

### Ship and world

**Ship**:
The craft a Cadet's program controls in the 3D world.
_Avoid_: Robot, avatar, character

**Ship API**:
The commands and sensors a program uses to control and read the Ship, identical in meaning and argument order in both languages: Python uses snake_case names, Java uses camelCase names.
_Avoid_: Ship commands, controls, library

**World State**:
The grader-readable state of the Ship and world entities during and after a run.
_Avoid_: Output, result, game state

**Seed**:
A key selecting one variation of a Mission's world layout. The first Seed is the practice layout a Cadet sees; the rest are hidden grading layouts.
_Avoid_: Random level, variant, version

### Help and contrast

**Training Wheels**:
The scaffold stage of Java starter code: full-scaffold, partial, or minimal, decreasing as Planets advance.
_Avoid_: Difficulty, help level, template

**Rosetta Pair**:
A short worked snippet in each language using the Planet concept, revealed after a Pass so a Cadet can compare Python and Java side by side.
_Avoid_: Answer, solution, translation

### Spaces

**Playground**:
An ungated free-coding space with no Pass and no Stars, where a Cadet builds Creations with code.
_Avoid_: Sandbox, free mode, practice level

**Creation**:
A world a Cadet builds in the Playground, with its goal set and draft code.
_Avoid_: Level, user level, map

**Challenge**:
A Creation copy judged against its goal set, shared so another Cadet can try it. A Challenge awards no Stars.
_Avoid_: Level, shared level, custom level

**Share Link**:
A link string carrying one Creation so it can be opened and copied. It is not program code, not a password, and not proof of identity.
_Avoid_: Invite, share code, challenge URL

**Arena**:
A challenge space outside the 25-Mission path, entered only with an Account, where the Ship fights drone waves under a tick function.
_Avoid_: Final level, boss fight, competition mode

**Hangar**:
The space where a Cadet selects Ship cosmetics unlocked by total Stars. Cosmetics are never bought with Stars and never affect progress.
_Avoid_: Shop, garage, store
