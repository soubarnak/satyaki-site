# JavaQuest

JavaQuest teaches Java to learners aged 9 to 12 through a space-robot quest with Bolt. One ordered set of levels leads to a final arena quest.

## Language

**Level**:
One ordered exercise teaching exactly one new Java concept.
_Avoid_: Lesson, stage, module

**Pass**:
State where output check and concept check both hold for a level.
_Avoid_: Win (except arena), complete, solved

**Concept token**:
Required code text proving the level concept was used.
_Avoid_: Keyword, marker, cheat check

**Badge**:
Named one-time milestone marker shown in progress view. First Print, Loop Master, and Bug Hunter are the v1 badges.
_Avoid_: Trophy, achievement, medal

**Content pack**:
The approved set of level stories, objectives, starter code, output checks, concept tokens, hints, points, and badge events. Lives in `docs/javaquest-level-pack.md`.
_Avoid_: Curriculum, lesson plan, question bank

**Bolt**:
Robot buddy who guides the learner through every mission.
_Avoid_: Mascot, assistant, tutor bot

**Cadet**:
Name Bolt uses for the learner in mission text.
_Avoid_: Player, student, user (in learner-facing text)
